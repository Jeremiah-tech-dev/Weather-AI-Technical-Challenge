# 🌿 FarmPulse — AI-Powered Farm Intelligence Platform

🔗 **Live Demo:** [https://weather-ai-technical-challenge.vercel.app](https://weather-ai-technical-challenge.vercel.app)

> 💻 **Best viewed on a desktop or laptop browser.**
> FarmPulse is built and optimised for desktop screens. For the best experience during your review, please open the live demo on a laptop or desktop computer rather than a mobile device. The dashboard layout, charts, and farm cards are designed for wider screens and may not display correctly on phones or tablets.

FarmPulse is a real-time farm monitoring dashboard built on top of the [Weather-AI API](https://weather-ai.co/docs). It gives agronomists and farmers a single, unified view of all their farms — live weather conditions, 7-day forecasts, hourly breakdowns, and AI-generated agronomic risk alerts.

Built as a technical assessment submission for **Weather-AI**.

---

## 🖥️ Trying the Live Demo

No setup needed — everything runs in your browser. Here's how to get the full experience in under a minute:

**1. Open the live link**
Head to [https://weather-ai-technical-challenge.vercel.app](https://weather-ai-technical-challenge.vercel.app). You'll be greeted by an animated splash screen — let it finish and it will take you to the landing page.

**2. Create your account**
Click **Register Account**. Enter any name, a phone number, and a password of your choice. Your password is hashed with bcrypt in the browser before being stored — plain text is never saved anywhere.

**3. Add your first farm**
Once on the dashboard, click **+ Add Farm**. Fill in the farm name, crop type, and region. On the next step, click **📡 Get My Location** — your browser will ask for location permission, click **Allow**. Your GPS coordinates will be captured and the farm will be saved.

**4. Explore the dashboard**
Your farm card will appear with live weather data — temperature, humidity, wind speed, and a risk badge (Safe / Watch / Act Now). Click **View details →** on any card to open the 7-day forecast chart, then click **⏱️ Load Hourly Forecast** to see the hour-by-hour breakdown.

**5. Check the Alert Feed**
Click **Alert Feed** in the navigation to view AI-generated agronomic risk flags across all your farms, filterable by severity.

**6. View your API quota**
Back on the dashboard sidebar, click **📊 View Quota Usage** to open a donut chart showing your Weather-AI AI call usage for the month.

> 💡 Each action loads data on demand — nothing auto-fires in the background. This is intentional to stay within the free tier API limits and give you a smooth, error-free experience.

## ✨ Features

- **Animated Splash Screen** — Particle-based canvas logo animation on first load
- **Secure Authentication** — Register and sign in with phone number + bcrypt-hashed password. Session is held in memory only (never persisted)
- **Live Weather Cards** — Per-farm real-time temperature, humidity, wind speed, and condition, auto-refreshed every 5 minutes
- **Risk Badges** — Each farm card shows a live Safe / Watch / Act Now risk level derived from WMO weather codes and condition strings
- **7-Day Forecast** — Bar chart showing daily high/low temperatures and rain probability (powered by Recharts)
- **Hourly Breakdown** — Line chart showing hour-by-hour temperature or rain probability, loaded on demand
- **AI Alert Feed** — Agronomic risk flags (high / medium / low severity) generated by Weather-AI across all farms, filterable by severity
- **AI Quota Tracker** — On-demand donut chart modal showing AI calls used vs. monthly limit with colour-coded health stages
- **GPS Farm Pinning** — Browser GPS used to capture precise farm coordinates when adding a new farm

## 🛠️ Tech Stack

| Layer | Technology | Why |
|---|---|---|
| Framework | React 19 | UI component library for building the interactive dashboard |
| Build Tool | Vite 8 | Fast development server and production bundler |
| Styling | Tailwind CSS v4 | Utility-first CSS for rapid, responsive UI design |
| Charts | Recharts | React-native chart library for forecast data visualization |
| Auth (client) | bcryptjs | Password hashing in the browser — plain text is never stored |
| API | Weather-AI REST API | Provides live weather, forecasts, insights and usage data |
| Serverless Proxy | Vercel API Routes | Server-side proxy that forwards requests to Weather-AI, bypassing browser CORS restrictions and keeping the API key server-side in production |

## 🚀 Getting Started

### Prerequisites

- **Node.js** v18 or higher
- **npm** v9 or higher
- A **Weather-AI API key** — get one free at [weather-ai.co](https://weather-ai.co)

### 1. Clone the repository

```bash
git clone https://github.com/Jeremiah-tech-dev/Weather-AI-Technical-Challenge.git
cd Weather-AI-Technical-Challenge
```

### 2. Install dependencies

```bash
npm install
```

### 3. Set up environment variables

Create a `.env` file in the project root:

```bash
cp .env.example .env
```

Then open `.env` and add your Weather-AI API key:

```env
VITE_WEATHERAI_KEY=your_api_key_here
```

> **Note:** The `VITE_` prefix is required by Vite to expose the variable to the browser bundle.

### 4. Start the development server

```bash
npm run dev
```

The app will be running at **http://localhost:5173**

## 🌐 Weather-AI APIs Used

| Endpoint | Where Used |
|---|---|
| `GET /v1/current` | Dashboard — live weather per farm card, refreshed every 5 minutes |
| `GET /v1/daily` | Farm Detail — 7-day forecast bar chart |
| `GET /v1/hourly` | Farm Detail — hourly temperature & rain line chart |
| `GET /v1/insights` | Alert Feed — AI agronomic risk flags per farm |
| `GET /v1/usage` | Quota modal — on-demand AI call usage donut chart |
| `GET /v1/weather-geo` | Add Farm Modal — reverse geo lookup on GPS pin |

## 🔒 Security Notes

- Passwords are hashed client-side with **bcrypt** (salt rounds: 10) before being stored in localStorage — plain text is never persisted
- User sessions are held **in memory only** and are cleared on tab close
- API budget is **enforced before every request** — once the monthly limit is reached, no further calls are made
- Farm coordinates are validated for bounds (`-90→90` lat, `-180→180` lng) before being sent to the API
- In production, all Weather-AI API calls are routed through **Vercel serverless functions** — the API key is never exposed in the browser bundle
